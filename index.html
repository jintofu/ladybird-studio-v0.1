Translation uses the standard nuclear genetic code. A translated sequence is only biologically meaningful when the correct CDS, transcript, strand and reading frame are known. This tool does not infer exon boundaries or identify the canonical LBX1 transcript.

MAPPING PROFILE

The same biological sequence can produce different musical interpretations depending on the mapping rules. These presets are artistic mappings, not biological properties of the bases or amino acids.

Amino-acid mode assigns each amino acid a stable pitch based on its one-letter code order in this application. Stop codons are rendered as rests. The mapping is deterministic and documented in the exported JSON.

METHOD NOTES & LIMITATIONS

What this prototype does

  • Accepts raw DNA and FASTA/TXT input.
  • Validates A/T/C/G and reports ambiguous symbols.
  • Supports forward and reverse-complement strands and frames +1/+2/+3.
  • Translates codons with the standard genetic code.
  • Generates deterministic pitch/rhythm events.
  • Plays audio in-browser and exports WAV, MIDI, PNG and JSON.
  • Runs locally without uploading sequence data.

What it does not claim

  • It does not predict gene function or protein structure.
  • It does not automatically annotate genomic DNA, exons, introns or UTRs.
  • It does not fetch verified LBX1 reference sequences.
  • Pitch assignments are artistic choices, not inherent biological frequencies.
  • Generative harmony and advanced multitrack composition are not in v0.1.
For a scientifically reproducible experiment, record the sequence accession/version, organism, transcript ID, sequence type (genomic/CDS/mRNA), strand, reading frame, genetic code table and complete mapping configuration with every export.

Keyboard / interaction

Use Analyze sequence to build events. Play starts the sequence; Stop cancels playback. Select a block in the visual score to inspect the associated base/codon/amino acid and note. Export Experiment downloads a JSON record of the current experiment.
